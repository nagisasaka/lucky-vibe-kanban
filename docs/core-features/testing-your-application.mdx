Use the Workspace **Logs** view to start or stop managed development servers, edit their scripts, select repository logs and open an application URL in your browser. See [Browser Testing](/browser-testing) for local, WSL, remote SSH tunnel and public HTTPS workflows, and for Chromium/Playwright/CDP inspection.

The legacy iframe browser, injected DevTools and click-to-component have been retired. Existing component context in saved conversations remains readable. You do not need to install the old Web Companion for LVK; LVK no longer provides its component-selection feedback workflow.
