---
title: "Boards and issues"
description: "Organise work in the projects stored on your LVK server"
---

Projects, issues, statuses, tags and comments are stored in your LVK server's SQLite database. Open the server URL to work with them. A separate Vibe Kanban Cloud account is not required.

Use the sidebar to create a [project](/boards/projects), then add [issues](/boards/issues). You can organise them in the [kanban board](/boards/kanban-board) or [list view](/boards/list-view), and use [filters](/boards/filtering) to focus on the work you need.

The server provides a local user and organisation identity. Cloud organisation invitations, billing, relay pairing and Cloud export are no longer available. Issue and comment uploads to Cloud storage have also been removed; Session and Workspace file attachments remain available.

For access from another device, deploy LVK using the [server container guide](/self-hosting/server-container) and open its HTTPS URL. External Runner execution uses the separate LVK Execution Bridge.
