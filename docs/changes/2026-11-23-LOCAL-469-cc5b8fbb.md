## 目的
LOCAL-464 のカンバン読み上げに、設定画面の独立した大項目「音声合成」（英語 Speech Synthesis）を追加する。Chrome でユーザーが実際に聞いて確認済みの読み上げの拡張。ボードのスピーカー On/Off は従来通りボードに残し、既定オフ。

## 仕様
- 音声: ブラウザが現在返す音声（Web Speech API の getVoices と遅延ロード時の voiceschanged）を一覧表示。「ブラウザの既定」を初期値にし、音声名と言語で識別できるようにする。Google 日本語などは実際に利用可能な場合だけ表示し、ベンダー名をハードコードしない。保存した音声が一時的にない・未対応なら既定にフォールバックし、選好自体は自動で消さない。
- 読み上げ速度: 1.0× を初期値に、0.5～2.0×の範囲で選べる（0.1刻みを目安）。SpeechSynthesisUtterance.rate を使い、体感や範囲は音声エンジン依存。設定値は試聴と通常の読み上げの両方に適用。
- 設定画面に短い固定文の「試聴」。ボードのスピーカーをオンにしたり、その待ち行列や現在の発話を切断したりしない。未対応ブラウザでも設定画面は壊さない。音声一覧は端末ごとに変わるため、永続化はブラウザ単位の既存設定パターンを使う。別タブに設定画面を開く場合も次の発話で値を反映できるようにする。
- LOCAL-464 の発話キュー、優先度、ミュート、取り込み条件を維持。サーバー側 TTS、DB 追加、別の音声通知機構は作らない。日英の UI 表記をそろえる。
- 既定・保存と再読込・遅延音声一覧・消失時のフォールバック・速度適用・試聴とボードの干渉を、対象の自動テストと可能な範囲でブラウザ確認。実音声を聞けたかどうかは別に報告。
