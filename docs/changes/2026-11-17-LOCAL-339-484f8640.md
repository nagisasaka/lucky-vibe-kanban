## 検討する改善方向
1. ブラウザ全体ではなく、実際に割り当てられたペイン幅に応じて本文幅を可変にする。
2. Issue / Workspace ともに最低限の左右余白を確保し、広いペインでは現在より広めの最大幅を候補として比較する。ヘッダーや区切り線まで一律に本文幅へ狭める必要はない。
3. Workspace の会話本文と入力欄の幅・左右位置をそろえる。Issue ではセクションの入れ子による二重 padding を避ける。
4. 長いコードや表は必要に応じてその領域内で横スクロールさせ、ページ全体の読みやすさを損なわない。
5. 幅調整のためだけに設定やスライダーを増やす前提にしない。自然に整う既定レイアウトを優先する。

左右余白 16〜24px、広い画面で 32px、最大幅 64rem 程度という値は、比較を始めるための参考候補にすぎない。実画面を見ずに確定仕様や必須条件にはしない。
