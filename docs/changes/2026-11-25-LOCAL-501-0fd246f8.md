公開用 LVK Docker イメージの `server` ターゲットに、既存ベースの公式 OS パッケージ `ffmpeg` を同梱する。利用者が、録画の切り出しや形式変換、NewsRoom などの媒体生成にそのまま使える汎用ツールとして提供する。

- Dockerfile の既存ランタイム用パッケージ導入経路に最小差分で追加。独自ビルドや Remotion／VOICEVOX の同梱、LVK 本体に動画機能を追加することは対象外。dev バンドルや稼働環境は変更しない。
- 配布候補で非 root の appuser から `ffmpeg` / `ffprobe` の実行と、人工短尺素材の動画変換・出力の読み取りを確認。追加前後を同じ条件で比較し、イメージ容量増分を報告。追加パッケージと依存のライセンス、著作権表示や対応ソース提供など配布条件を一次資料で確認し、必要な対応と残課題を記録する。法的結論を推測しない。
- LOCAL-495 の既存イメージは比較基準として保持。dev ビルドと重いイメージビルドを重ねない。通常の workspace に Docker がなければ、Dockerfile の実装とローカルでできる検証まで進め、イメージ検証用の手順・条件を残して報告。後で VPS 側の既存ビルダーとキャッシュを使用し、隔離イメージでのみ検証する。
