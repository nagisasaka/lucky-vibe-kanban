## 結論
ファイルエクスプローラの Markdown プレビューで、先頭の YAML フロントマターを本文から分離し、既定で閉じた「メタデータ」として表示する。

## 背景
イシュー本文の控え（例：`docs/changes/2026-11-24-LOCAL-460-ca49b042.md`）を開くと、先頭のメタデータが大きな見出しのように描画され、本文より目立つ。LVK 固有ファイルだけを特別扱いせず、汎用の Markdown プレビューとして対応する。

## 確認条件
- 正しく閉じた先頭の YAML フロントマターは Markdown 本文の描画に流さない。初期表示では本文が主役。メタデータを展開するとキーと値を読める。
- `title` は本文の大見出しに自動昇格させない。フロントマターのないファイルや本文中の `---` の表示は従来どおり。壊れたフロントマターを理由に本文を消さない。
- ソース表示やファイル内容は変更しない。イシュー本文の Git 保存と再マージの仕様は別件。
- イシューの控え形式と一般の Markdown の両方で、通常表示・展開・ソース表示を確認する。
