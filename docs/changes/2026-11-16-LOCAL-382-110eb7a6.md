## 結論
Claude Code の配色検討で採用した M2 を製品の「カラーテーマ」に実装する。Initial は調査時点の記録。今回は実装に進む。

- ThemeMode は「システム / ライト / ダーク」のまま。ライトの配色は「標準（白） / Paper / Linen」、ダークは「標準（チャコール） / Navy / Indigo」。ライト・ダークそれぞれの既定は標準、ブランドオレンジは共通。
- 選択したテーマモードの配色カードを1行表示。「システム」なら OS がライトのとき・ダークのときの2行を表示。それぞれ独立保存。インスタンス共通、保存した時点で反映。旧設定からは標準へ移行し、現在のモードを維持する。
- 新しいテーマモードや画面の分岐を増やさず、配色の違いは共通トークン／CSSで扱う。標準ライト／ダークの意味色とオレンジのコントラストを同時に直し、オレンジの塗りボタンには十分に濃い文字色を使う。
- 配色、背景・テキスト・状態色、設定のプレビューと操作は既存の M2 モック／研究結果を参照。キーボード操作と focus、主要画面（ボード、Issue、Workspace、設定）で読みやすさを確認する。
- 受入：旧設定の互換性、システムの明暗切替、それぞれの配色の保存・読み戻し、保存前に本適用されないこと、主要組合せのコントラストを検証。テーマ関連に限定し、他の設定や保存機構を広げない。
