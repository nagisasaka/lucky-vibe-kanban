# Agreed Issue

Use this outline when creating or materially updating requirements. Fill it with
the actual agreement; omit inapplicable sections. Preserve the user's terminology.

- Purpose and expected behaviour
- Scope and explicit exclusions
- Constraints and compatibility requirements
- Acceptance criteria and relevant verification
- Necessary unresolved decisions

A title alone is not an implementation specification. Do not include unrelated
conversation history or personal preferences. Include a source conversation link
only when the actual link is available; do not invent a ChatGPT URL.
